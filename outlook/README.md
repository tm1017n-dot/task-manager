# Outlook予定表への手動連係（最新HTML版）

このフォルダーの `Install_Outlook_Sync.vbs`、`Sync_Outlook.js`、`Uninstall_Outlook_Sync.vbs` を一緒に配布します。Windows 10/11、従来版Outlook（「ファイル」タブあり）、Edge、Windows Script Host が必要です。管理者権限、サーバー、PowerShell、Graph APIは不要です。

設定・削除・同期結果・エラーのダイアログは日本語で表示します。

## 各PCで一度だけ設定

1. 配布した3ファイルを同じフォルダーに置き、`Install_Outlook_Sync.vbs` を実行します。
2. 各利用者がポータルで選択するものと**同じ共有JSON**のフルパスを入力します。例：`\\server\share\personal_work_portal_shared.json`。参照用のサンプルJSONは指定しないでください。
3. インストーラーは `%APPDATA%\WorkPortalOutlook\Sync_Outlook.js` へヘルパーをコピーし、現在のWindows利用者のレジストリに起動リンクとJSONパスを登録します。全利用者に設定する場合は各自のWindowsアカウントで繰り返します。
4. ポータルで「共同利用」から共有JSONに接続し、上部の「自分」を選び、「Outlookへ反映」を押します。初回はEdgeが外部アプリを開く確認を表示する場合があります。

Outlookに「業務ポータル」という専用の予定表を作り、共有JSONの**選択した利用者IDの未完了タスクのうち、有効な期限があるもの**を終日予定として反映します。Outlookでこの予定表の表示をオンにしてください。予定は「予定なし」（BusyStatus=0）、通知なしです。タスクIDと利用者IDで識別し、ボタンを繰り返し押しても予定を重複させません。期限日や件名は更新されます。

対象から外れた連係済み予定（完了、担当変更、削除など）は、件数と件名を提示してから、削除の可否を尋ねます。「いいえ」なら残ります。自分が手入力した予定や別利用者の連係済み予定は触りません。専用予定表の連係済み予定を手動編集した場合、次回の連係で件名や日付はタスク側の値に戻ります。

業務日誌の本文、所要時間、個人メモ、タスクのメモはOutlookへ渡しません。ポータルはOutlookへの反映結果を共有JSONへ書き戻さず、連係は一方向です。OutlookがMicrosoft 365のメールボックスに同期する環境では、**予定件名と期限日がそのメールボックスへ保存されます**。運用に適したタスク名にしてください。

## 再設定・削除

- 共有JSONのパスを変更した場合は、インストーラーを再実行して新しいパスを指定します。
- `Uninstall_Outlook_Sync.vbs` で起動リンク、設定、端末内ヘルパーを削除します。Outlookの既存予定表と予定は残るため、不要ならOutlookで確認して削除します。
- 新しいOutlookにはこの方式を使えません。庁内ポリシーでWindows Script Host、JScript、カスタムURLの起動が制限される場合は連係できません。

## 受入確認

1. 担当タスク２件と担当外タスク１件を用意し、ボタンで専用予定表へ２件だけ追加される。
2. 再度押すと追加０件、更新２件で予定が重複しない。
3. タイトル・期限を変更すると同じ予定が更新される。
4. 完了または担当変更後、削除確認で「いいえ」なら残り、「はい」なら対象だけ削除される。
5. 共有JSONが読めない、形式が違う、本人IDが存在しない場合は書込せずエラーになる。
6. 業務日誌と個人メモが予定に入らない。ライト／ダーク切替後も同じボタンが使える。

Outlook COMとWindowsのカスタムURL起動はLinux上では試験できません。導入先のWindows/Edge/従来版Outlookで上記を確認してから本番利用してください。
