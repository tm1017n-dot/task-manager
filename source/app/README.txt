業務ポータル 最新HTML版（v10.1互換）

index.htmlは1本です。画面上部でライト／ダークを切り替えられます。

1. index.html を Microsoft Edge で開いてください。
2. 初回は ドキュメント\00_導入ガイド.txt を参照してください。
3. 画面確認用JSONは サンプルデータ フォルダーにあります。
4. index.html と icon.ico は常に同じフォルダーへ置いてください。
5. 一括VBSから導入した場合、同じフォルダーにアイコン付きの「業務ポータル」ショートカットが作成されます。

構成
・index.html / icon.ico：アプリ本体
・サンプルデータ：復元用ダミー、共有ダミー、空の共有JSON
・ドキュメント：導入、利用者、管理者・共同利用、設計、運用・保守、確認表

注意
・共同利用はMicrosoft Edgeで同じ共有JSONを選択します。
・業務日誌は各PCのブラウザーに個人保存されます。
・ホームは件数と対象タスクを一体表示します。
・共有活動ログは「共同利用」で全履歴を検索できます。
・ダミーURLと共有フォルダーパスは実在しない例です。

・画面上部の配色ボタンでライト／ダークを切り替えられます。
・従来版Outlookへの連係には、同じフォルダー内のoutlook/インストーラーを各PCで一度実行してください。アプリのフォルダーを移動したら再設定が必要です。
