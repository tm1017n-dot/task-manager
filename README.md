# 業務ポータル

共有ファイルサーバー上の共有JSONを中心に、少人数で利用する業務管理ツールです。

## 配布物

- `source/app/` — ライト／ダーク切替を内蔵した最新HTMLソース（1本）
- `release/` — v10.1ライト版・ダーク版の作成VBSと配布用ZIP
- `docs/HANDOVER_DESIGN_V10.1.md` — 保守・改修を別プロジェクトへ引き継ぐための設計書
- `checksums/SHA256SUMS.txt` — 配布物のSHA-256値
- `outlook/` — 従来版Outlook向けの端末用連係ヘルパー、初回インストーラー、削除用VBS、導入手順
- `release/Outlook連携インストーラー_latest.zip` — 上記の端末用ファイルをまとめたZIP
- `release/業務ポータル_latest_HTML_導入一式.zip` — 配色切替対応のHTML、サンプル、ドキュメント、Outlook連係をまとめた導入用ZIP
- `release/業務ポータル_一括インストーラー_latest.vbs` — 最新HTML版とOutlook連係ファイルを内包する単体のVBSインストーラー。実行したVBSと同じフォルダーに `index.html` とアイコン付きの `業務ポータル.lnk` などを配置し、必要なら従来版Outlookの設定へ進みます。
- `release/業務ポータル_一括インストーラー_20260929_r3.vbs` — 上記と同じ内容の第3版配布ファイル。起動時に「2026年9月29日・第3版」と表示します。従来のライト／ダーク作成VBSは旧版用です。

最新HTMLソースには、KPIとタスク一覧を一体化したホーム、全件検索できる共有活動ログ、見やすさを高めたライト／ダークテーマが含まれます。`release/` のライト／ダーク作成VBSはv10.1安定版、一括インストーラーVBSは最新HTML版です。

最新HTML版は画面上部のボタンでライト／ダークを切り替えられます。従来版Outlookを使うPCでは、`outlook/README.md` に沿って一度だけ端末用連係を設定すると、上部の「予定表選択」で反映先を指定し、「Outlookへ反映」から自分の未完了・期限ありタスクを指定先へ反映できます。Outlook予定は本人のメールボックス側にも保存され得ます。安定版の作成VBSにはこれらの機能は含まれません。

実行時は `index.html` と `icon.ico` を同じフォルダーに置き、Microsoft Edgeから開いてください。ホームの「自分／全体」はダーク配色でも選択状態が明瞭に分かる表示です。

一括インストーラーは、VBSを置いた書込可能なフォルダーにアプリ一式とアイコン付きショートカットを配置します。Edgeを検出できればショートカットはEdgeで起動し、検出できなければ既定のブラウザーで開きます（共同利用にはEdgeを使用）。同名の既存ファイルだけを「業務ポータル_旧版_…」フォルダーへ退避し、共有JSONとブラウザー内の個人データには手を加えません。以前の別の場所で使っていた個人データは自動移行されないため、必要なら旧画面でバックアップを取得してください。以前のデスクトップショートカットは旧パスを指すため、新しい同梱ショートカットを使ってください。共有JSONへの接続は画面から行い、Outlook連係の設定時は既存の共有JSONのフルパスを入力してください。生成元は `scripts/build_full_installer.py` です。Windows/Edge/Outlookでの実機確認は導入先で行ってください。

導入・Outlook連携の設定・同期結果などの確認ダイアログは日本語で表示します。VBSを置いたフォルダーが導入先になるため、別の場所へ導入したい場合は実行前にVBSをそのフォルダーへ移してください。
