# 業務ポータル v10.1

共有ファイルサーバー上の共有JSONを中心に、少人数で利用する業務管理ツールです。

## 配布物

- `release/` — ライト版・ダーク版の作成VBSと配布用ZIP
- `docs/HANDOVER_DESIGN_V10.1.md` — 保守・改修を別プロジェクトへ引き継ぐための設計書
- `checksums/SHA256SUMS.txt` — 配布物のSHA-256値

v10.1を安定版として保管しています。実行時は、VBSを展開後に `index.html` と `icon.ico` を同じフォルダーに置いた状態で、Microsoft Edgeから開いてください。
